# pax-verify

## Execution Contract
- 前置门禁：可被任意 L0/L1/L2 调用；被验证对象与成功标准可读取
- 未通过门禁：返回 `blocked`
- 版本检查：`pax-ops/versions.json`
- 独立：验证不依赖被验证对象的自证
- 可审计：每次印章必须可追溯到具体证据
- 跳过留痕：任何跳过记录 `skip_reason`（跳过留痕契约）

## 职责边界
- 做什么：运行中验证，有界循环 + 五态印章
- 不做什么：不认领路由落点、不改变主流程、不修改快照字段

## 输入
- 必需：被验证对象（执行结果 / 变更 diff / 输出）与成功标准
- 可选：超时预算、重试次数

## 工作流
1. 读取被验证对象与成功标准
2. 有界循环执行验证（默认上限 3 次，超过升级）
3. 逐项对照标准，记录证据
4. 输出五态印章

**五态印章**：

| 印章 | 语义 |
|---|---|
| `pass` | 全部标准通过 |
| `fail` | 存在未通过项 |
| `partial` | 部分通过，允许延期 |
| `blocked` | 证据不足或依赖不可用 |
| `escalated` | 超出验证权限 |

## 输出契约
- 五态印章（含证据与置信度），格式由 `schemas/snapshot.schema.json` 约束

## 失败模式
- 验证标准缺失 → 返回 `blocked`
- 循环超过上限 → 强制收敛并返回 `partial`
- 跳过留痕：任何跳过记录 `skip_reason`

## 何时升级
- 问题超出验证范围 → 请求人工介入
- 高风险或未决争议 → 升级至主流程或人工审批
